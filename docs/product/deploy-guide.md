# 배포 — 폰에서 말로 고친 것을 내보내기

2026-10-25 정함. 2027년 2월부터 대표 혼자 운영하므로, 출장 중에도 Claude 앱에 "이거 고쳐서 올려 줘"라고만 하면 Claude가 알아서 서버·앱·웹에
반영하고 결과를 알려 주는 방식으로 만들었다. 기술 절차는 `docs/engineering/deploy-runbook.md`.

## 두 곳에 올린다

| | 프리뷰(데모) | 프로덕션(운영) |
|---|---|---|
| 누가 보나 | 나, 소속사 시연(입장 코드), 테스트 폰 | 실제 팬·아티스트·소속사 |
| 주소 | `demo.toffeechat.app` · 앱 "Toffee Dev" | `app.toffeechat.app` · 스토어 앱 "Toffee" |
| 데이터 | 가짜, 매일 새벽 초기화 | 진짜 — 결제·대화 기록 |
| 올리는 법 | Claude가 바로 | Claude가 준비 → **내가 폰 GitHub 앱에서 "승인"** |
| 지금 | 있음 | 아직 없음(사업 본부 "운영 전환" 탭 2단계에서 만듦) |

## 말하는 법 — 정해진 말 없음

- "올려 줘", "반영해", "적용해 줘", "폰에서 보이게 해 줘" → **프리뷰**.
- "운영에", "실제 사용자한테", "스토어에", "팬들한테 나가게" → **프로덕션**(먼저 프리뷰에 올라가 확인된 것만).
- 헷갈리면 Claude가 한 줄로 물어본다: "프리뷰(데모)에 올릴까요, 운영에 올릴까요?"
- "되돌려" → 직전 상태로.

## Claude가 알아서 판단하는 것

고친 파일을 보고 무엇을 올릴지 정한다 — 내가 "서버도 올리고 앱도…"라고 말할 필요 없음.

- **서버**를 고쳤으면 서버를, **DB 구조**가 바뀌었으면 서버를 켤 때 같이 바꾼다.
- **앱 화면·문구**만 고쳤으면 **OTA**(앱을 다시 깔지 않고 껐다 켜면 바뀜)와 웹을.
- **앱의 폰 기능**(새 권한·새 부품·앱 아이콘 등)을 바꿨으면 OTA로 안 되고 **새로 빌드**해야 한다 — 운영은 **애플·구글 심사가 1~2일** 걸려서 Claude가 먼저 알려 준다.
- 새 빌드 전에 그동안 고친 화면 수정은 지금 깔린 앱에 먼저 OTA로 보낸다(젤리에서 순서를 거꾸로 했다가 옛 버전 사용자가 몇 주 동안 수정을 못 받은 일이 있음).

## 안전장치

1. **운영엔 데모에서 확인된 것만.** 급한 수정도 데모를 먼저 거친다 — 대신 자동 점검만 통과하면 바로 넘어가서 몇 분이면 된다.
2. **운영 데이터는 손으로 안 고친다.** 회원 정지·환불·역할 변경 같은 건 운영자 화면 기능으로. 화면에 없는 일이 꼭 필요하면 백업 → 미리보기(몇 줄이 바뀌는지) →
   내가 두 번 승인하는 별도 절차로만. 같은 일이 또 생기면 운영자 화면 기능으로 만든다.
3. **DB 구조는 "추가 먼저, 지우기는 다음에".** 팬 폰엔 옛 버전 앱이 몇 주씩 남아 있어서, 한 번에 지우거나 이름을 바꾸면 옛 앱이 고장 난다. 그래서 새 것을 먼저 더하고,
   아무도 옛 것을 안 쓰게 된 다음 배포에서 지운다. "업데이트해야 쓸 수 있어요" 강제 업데이트는 정말 필요할 때만(Claude가 먼저 묻는다).
4. **올린 뒤 자동 점검** — 서버가 살아 있는지, 로그인이 되는지, 메시지를 보내고 받고 답장할 수 있는지, 웹 첫 화면이 뜨는지를 숨겨 둔 점검 전용 계정으로 확인하고
   결과를 알려 준다(실제 팬·아티스트에게는 보이지도, 알림이 가지도 않음). 새로 생긴 오류(Sentry)도 같이 본다. 실패하면 Claude가 **되돌리기를 제안**한다.
5. **피하는 시간** — 데모: 매일 새벽 초기화 시간(태국 4시 전후), **소속사 미팅 2시간 전부터 끝날 때까지**(미팅 일정을 Claude에게 말해 두면 그 시간엔 데모를 안 건드림).
   운영: 태국 저녁 7시~새벽 1시(팬이 가장 많이 쓰는 시간) — 장애 수정만 예외.

## 운영 배포 승인하는 법 (폰)

1. Claude가 "운영 배포 준비됐어요 — 서버·웹·OTA, DB 구조 변경 없음" 같은 요약과 링크를 준다.
2. GitHub 앱 → 알림(또는 저장소 → Actions → Deploy production) → **Review deployments** → `production` 체크 → **Approve**.
3. 10~20분 뒤 Claude가 결과(자동 점검·새 오류)를 알려 준다.
