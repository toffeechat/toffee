## 순서를 정하는 세 가지 전제

1. **실제 아티스트는 소속사 계약 전엔 못 올린다** → 그 전까지는 가상 아티스트 데모로 보여준다.
2. **유료 판매는 법인 설립 후, 법인 명의 스토어 계정으로** → 법인 전엔 내부 테스트만.
3. **목표는 2027년 2월 유료 오픈**(사용자 목표 — 아이디어 싸움이라 빠르게): 11~1월에 소속사 연락·계약·운영 준비를 끝내고 2월에 연다.
   그래서 **법인은 소속사 반응이 오는 대로(12월) 바로 세운다** — 지원사업 결과를 기다리지 않는다.
   **예비창업패키지는 3순위 대안**(소속사 쪽이 잘 안 될 때만). 사업자를 내면 예비창업자 자격이 없어지므로, 법인을 세운 뒤엔 초기창업패키지 등으로 간다.
   *(2026-10-19 정정: 예전 이 문서는 "예비창업패키지 결과 뒤 법인 → 2027년 여름 출시"였는데 사용자 목표와 달랐음)*

## 4단계. 지원사업 (3순위 대안 — 11/30에 의향 0곳일 때)

  대학 창업지원단(KAIST·충남대·한밭대 — 예비창업패키지 주관기관, 재학생 아니어도 됨), 글로벌·콘텐츠 계열(한국콘텐츠진흥원 등)
- [ ] 신청: 예비창업패키지(청년) + 대전 지역 사업. **재직자 신청 가능 여부**와 **현금 자부담**은 공고마다 다르니 확인

> 지원금은 **자본금이 아니다**. 협약한 용도(외주·마케팅·법률 검토 등)에만 쓰고 증빙·정산하는 돈이라 법인 자본금이나

**떨어져도** 법인 설립 후 초기창업패키지(업력 3년 이내)나 지역 사업으로 다시 도전한다.

## 경쟁 서비스 벤치마킹 — 버블·위버스 DM (2026-09-30)

팬 입장에서 **돈을 내고 두 달 써 보는 것**이 목적이다. 기능 목록은 이미 알고 있으니, 문서로는 모르는 **느낌·빈도·결제 경험**을 본다.
기록은 짧게: 날짜 + 한 줄 + 스크린샷(개인 폴더에만 — 경쟁사 화면은 제안서·공개 자료에 넣지 않는다).

**비용**: 아티스트 1명당 월 4천~5천 원 안팎(서비스·결제 수단마다 다름, 결제 전 앱에서 확인) × 두 서비스 × 1~2명 × 2개월
→ **약 2만~5만 원**. 갱신일 전에 해지하는 걸 잊지 않는다.

보는 것(체크 = 그 부분을 보고 토피에서 어떻게 할지까지 정했다는 뜻, 2026-10-21):
- [x] **가입~첫 메시지**: 앱 설치부터 첫 메시지를 받기까지 몇 단계·몇 분인지, 결제 화면의 가격 표시·안내 문구
- [x] **스타 발송 빈도·형식**: 하루 몇 개, 글·사진·음성·영상 비율, 몇 시에 오는지, 오래 안 오면 어떤 기분인지
- [x] **팬 답장 규칙**: 글자 수·횟수 제한, 구독 기간에 따라 늘어나는 방식(버블), 내 답장이 읽혔는지 알 수 있는지
- [x] **이름 부르기·개인화**: 스타 메시지에 내 닉네임이 들어가는 방식, 어색하지 않은지
- [x] **알림**: 알림 문구, 여러 개가 몰릴 때, 알림을 누르면 어디로 가는지
- [x] **번역**(위버스): 번역 품질, 버튼 위치, 기본으로 번역돼 보이는지 눌러야 보이는지
- [x] **저장·보관**: 사진·영상 저장, 모아보기, 유출 금지 안내 방식
- [x] **해지·환불**: 해지 경로와 문구, "다시 구독하면 이전 대화가 안 보인다" 안내가 어디서 나오는지, 환불 안내
- [x] **돈을 더 쓰게 만드는 장치**: 묶음·할인, 기념일, 유료 부가 기능
- [ ] **불편했던 점**: 토피가 이길 수 있는 지점(→ 제안서 차별점)
