# 검볼(Gumball) — 예매·스트리밍권 플랫폼 기획 메모

디저트랩 아래 세 번째 서비스. 젤리(커뮤니티) → 토피(유료 1:1 메시지) → **검볼(예매)**.
이 문서는 "지금 기준으로 정한 것"만 모아 둔다. 정하게 된 이야기는
`STATUS.md` 아이디어 보관함(2026-10-22 방향 정리)과 `docs/deployment-readiness-plan.md` 2026-10-28 항목.

## 한 줄

**업자 없는 예매처.** 인기 공연은 추첨으로, 토피 구독 팬은 먼저, 못 가면 정가로 반납 → 대기 팬에게.
이름은 동전을 넣고 돌리면 공이 무작위로 하나 나오는 검볼 기계(= 추첨)에서 왔다.

## 언제 만드나 (2026-10-28 사용자 결정)

- **운영(실제 판매)은 맨 나중** — 공연 주최사가 공식 예매처로 써 줘야 가능하고, 토피 출시(2027-02)가 먼저.
- **개발은 시간 날 때 틈틈이 미리** 해 둔다. 토피 일정을 밀지 않는 선에서.

## 정한 것 (2026-10-28)

| 항목 | 정한 것 |
|---|---|
| 이름 | 검볼(Gumball) 확정. 쓰기 전에 상표·도메인·앱스토어 이름 확인 |
| 대표색 | 디저트랩 한 가족 — 젤리 **퍼플**(#A888FF) · 토피 **블루**(#7C8CFF) · 검볼 **코랄**(#FF8A7A) |
| 분위기 | 포인트색만이 아니라 화면 전체를 코랄에 맞춘 따뜻한 톤 — 바탕 #FFF7F4, 글자 #2A1612(짙은 갈색), 보조 글자 #7A5A52, 선 #F1DDD6, 연한 코랄 #FFE6DF, 흰 글자 버튼 딥 코랄 #C4432F, 어두운 화면(티켓) #3A1D17. 토피 블루는 "토피 구독 팬" 표시에만 |
| 화면 | **웹과 앱 둘 다** — 토피처럼 코드 하나로 아이폰·안드로이드·웹 |
| 저장소 | 토피와 **따로**(토피는 main에 합치면 데모가 자동 배포돼서 섞이면 위험) |
| 표 종류 | 처음부터 4개 — **지정석**(좌석 하나하나) · **스탠딩**(구역 + 입장 번호) · **비지정석**(수량) · **스트리밍권**(온라인 시청 + 다시 보기) |
| 결제 | 먼저 **가짜 결제(테스트)**로 흐름을 다 만들고, 결제대행(PG)은 나중에 연결 |
| 토피 계정 | 연결함 — "토피로 로그인". **토피 구독 팬 선예매는 공연마다 켜고 끄기** |
| 스트리밍권 판매 | **웹에서 팔고 앱은 시청만**(앱 안에서 디지털 시청권을 팔면 스토어 결제 수수료 15~30%가 붙을 수 있음). 앱 안 판매 여부는 출시 전 스토어 규칙 확인 뒤 설정으로 |
| 수수료·환불·법 | **지금 정하지 않음.** 설정값(수수료율·취소 기한·재판매 수수료·1인 매수·양도 횟수)으로 만들어 두고 나중에 숫자만. 판매자는 **주최사, 검볼은 중개**로 가정 |
| 첫 고객 | 개발엔 상관없음. 팔 때는 토피와 계약한 소속사부터 |

## 이미 정해 둔 업자 거르기 (2026-10-22)

- 살 때: 토피 구독 팬 선예매, 인기 공연 추첨, 공연당 1인 2장 + 동행자 등록(동행자도 본인 인증 계정), 웃돈 판매 신고 보상
- 못 갈 때: 취소 기한 전엔 취소, 뒤엔 정가 반납 → 조건(회차·구역·장수) 맞는 대기 팬 중 추첨으로 바로 결제
- 선물: 지정 양도 1번(받은 사람은 반납만), 정가 이하
- 입장: 몇십 초마다 바뀌는 QR(캡처 무효, 인터넷 없이도) + 입장 직원 화면
- 해외 팬: 여권 인증·여권 영문 이름, 나라별 결제, 현지 통화·현지 시간, 9개 언어
- 매크로: 완벽히 막는 대신 "써도 이득 없는 구조"(추첨·1인 1계정·선예매·표를 사람에 묶기)
