## 검토 의견 (Claude, 2026-10-25)

**좋은 점**
- 회사 이름과 결이 맞다 — 토피·젤리·검볼 모두 단 것이라 "디저트 연구소" 아래 한 가족으로 설명된다.
- 퍼플 블루 `#7C8CFF`가 토피 앱 포인트 색과 같아서 토피 제안서·스토어 판매자 화면과 나란히 놓여도 어색하지 않다.
- 스토리보드 구성(조합형·단색·여백·최소 크기)은 처음 만든 로고치고 빠진 게 거의 없다.

**고칠 것(중요한 순)**
1. **메타(Meta, 페이스북) 로고와 많이 닮았다.** 파란 계열 그라데이션의 무한대(∞) 리본은 메타 로고의 가장 큰 특징이라
   소속사·투자자가 처음 볼 때 "메타 같다"가 먼저 떠오를 수 있고, 나중에 로고를 상표로 낼 때도 유사 판단 위험이 있다.
   → 무한대 모양을 버리거나, 디저트를 떠올리게 바꾸는 쪽을 추천(예: 마카롱 단면·숟가락·실험 플라스크 안의 젤리처럼 "디저트 + 랩"이 보이는 형태,
   또는 D·L 글자를 쓴 단순한 모양).
2. **스토리보드와 실제 파일이 다르다.** 스토리보드는 입체로 꼬인 리본인데 SVG는 납작한 한 덩어리이고, 두 고리가 한 점으로만 붙어 있다.
   작게(16~24px) 쓰면 붙은 점이 사라져 **두 개의 물방울(또는 나비넥타이)**처럼 보인다. 왼쪽이 오른쪽보다 큰 것도 의도인지 정해야 한다.
3. **글자(워드마크)가 윤곽선이 아니라 글꼴 이름(Arial)으로 들어가 있다.** 컴퓨터마다 다른 글꼴로 보일 수 있고, 스토리보드의 글자 모양과도 다르다.
   글자 간격(-3)이 좁아 `rt`가 붙어 보인다. → 라이선스가 자유로운 글꼴(예: Pretendard, OFL)로 다시 쓰고 **윤곽선으로 변환**해서 저장.
4. "black" 심볼 SVG 안에 쓰지 않는 그라데이션 정의가 남아 있다(보이는 데는 문제없음, 정리만).
5. 스토리보드 설명 문구 끝에 "…표현합니다. 다"처럼 글자가 하나 더 붙어 있다.

**급하지 않은 이유**: 법인 등기·스토어 판매자 이름은 글자(디저트랩·Dessert Lab)라 로고가 없어도 설립·출시에 지장이 없다.
1번(메타 유사)만 정리하고 3번(윤곽선)을 하면 내부·외부 자료에 쓰기엔 충분하다. 회사 로고의 상표 출원은 지금 할 필요 없다(토피·젤리 상표가 먼저).

## 이름 확인(남은 일)

- 인터넷등기소: 대전 관할에 같은 이름("디저트랩")·같은 목적의 법인이 있는지.
- KIPRIS: "디저트랩"·"DESSERT LAB" — 카페·베이커리(30·43류)는 많을 수 있지만 앱·소프트웨어(9·42류)·플랫폼(35류) 쪽에 있는지가 중요.
