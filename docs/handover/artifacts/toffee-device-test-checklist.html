시작 전에

폰: 설치한 Toffee Dev 앱 · PC: demo.toffeechat.app (같은 데모 서버라 서로 연결돼요). 폰으로 팬, PC로 아티스트를 같이 켜 두면 푸시·실시간 확인이 쉬워요.

데모 계정은 로그인 화면의 입장 코드 로그인으로 들어가요. 이메일만 넣고, 입장 코드는 Railway → toffee → Variables → DEV_LOGIN_CODE(눈 아이콘)에 있어요.

이 칸은 본인만 볼 수 있는 곳에 저장돼요(공유해도 다른 사람에겐 안 보임). Claude에게도 보내지 않아요.

다 하고 나면 운영자 → 데모 초기화로 처음 상태로 돌아가요. 대신 테스트 중에 소셜 로그인으로 새로 생긴 계정도 같이 지워지니, 폰 앱은 한 번 로그아웃 후 다시 로그인하세요(푸시 기기 등록도 다시 돼요). 이 체크리스트 결과는 지워지지 않아요.

데모 초기화 방법

테스트로 생긴 메시지·구독·계정을 지우고 처음 데모 상태로 돌려요. 테스트를 다 하고 맨 마지막에 하세요.

  1. PC에서 demo.toffeechat.app → 입장 코드 로그인 → admin@toffee.demo
  2. 운영자 첫 화면을 맨 아래까지 내려서 데모 초기화 누르기
  3. 확인 창에서 초기화 → "초기화하는 중…"이 끝날 때까지 기다리기(10초 안팎)
  4. 폰 앱: 프로필 → 로그아웃 → 다시 로그인(소셜 계정은 새로 만들어지고 푸시 등록도 다시 됨)
  5. 원하면 이 체크리스트에서 결과 모두 지우기(맨 아래)로 새로 시작

지워지는 것: 메시지·답장·신고·차단·구독·환불·정산 마감, 새로 만든 아티스트·CP·묶음·소속사, 소셜 로그인으로 생긴 계정, 폰 푸시 등록. 그대로: 데모 계정 6개(같은 이메일로 다시 로그인), 앱 설치, 서버 설정, 이 체크리스트 결과.

버튼이 안 보이거나 실패할 때: Railway → toffee → Variables → DEMO_SEED를 reset으로 바꾸고 Deploy → 배포가 끝나면 다시 true로 바꾸고 Deploy(이걸 안 하면 배포할 때마다 초기화됨).

문제가 생긴 화면은 캡처해서 대화에도 같이 보내 주시면 더 빨리 고칠 수 있어요.
