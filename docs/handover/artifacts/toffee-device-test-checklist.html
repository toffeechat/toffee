항목마다 통과 · 문제 · 건너뜀을 누르고, 문제면 무슨 일이 있었는지 메모에 적습니다. 바로 저장되고 Claude가 읽어서 고칩니다.

지금 할 것

  • 11-24 preview 빌드를 깐 폰으로 확인
  • 먼저 로그인 5종 → 그다음 푸시·사진·영상·음성·카메라
  • 시작 전에 운영자 → 데모 초기화 한 번
자세히
  • 폰 항목은 11-24 새 preview 빌드를 깐 뒤에 확인해 주세요. 앱 틀(React Native)이 통째로 바뀌어서, 그 전에 누른 폰 결과는 "이전 빌드 결과"로 흐리게 보이고 다시 확인할 항목으로 돌아왔습니다.
  • 가장 먼저: 로그인 5종(애플·구글·카카오·네이버·LINE). 새 빌드에서 아이폰 소셜 로그인이 앱으로 돌아오는 부분을 새로 짰습니다. 로그인 뒤 앱으로 못 돌아오면 바로 문제로 눌러 주세요.
  • 그다음 푸시(앱을 닫아도 오는지)·사진·영상·음성 보내기·카메라입니다.
  • 탈퇴할 때 스토어 구독 안내(11-24)는 새 빌드 다음 OTA에 들어갑니다. 실제 스토어 구독이 있어야 상자가 보여서 1월 샌드박스 때 확인합니다.
  • 시작 전에 운영자 → 데모 초기화 한 번(아래 "데모 초기화 방법"). 제목에 1월이 붙은 항목은 스토어 상품 등록 뒤에만 할 수 있어요.

내가 확인 = 실제 폰이 있어야 되는 항목(소셜 로그인·푸시·카메라·녹음·캡처·진동·스토어 결제). Claude 확인 = 매달 첫째 주 화요일 월간 점검 때 Claude가 데모 웹으로 보고 [Claude 날짜] 메모를 남김.

데모 초기화 방법

테스트로 생긴 메시지·구독·계정을 지우고 처음 데모 상태로 돌려요. 테스트 시작 전 한 번, 다 하고 맨 마지막에 한 번 하세요.

  1. PC에서 demo.toffeechat.app/?as=admin → [운영자] → 운영자 입장 코드
  2. 운영자 첫 화면을 맨 아래까지 내려서 데모 초기화 누르기
  3. 확인 창에서 초기화 → "초기화하는 중…"이 끝날 때까지 기다리기(10초 안팎)
  4. 폰 앱: 프로필 → 로그아웃 → 다시 로그인(소셜 계정은 새로 만들어지고 푸시 등록도 다시 됨)

지워지는 것: 메시지·답장·신고·차단·구독·환불·정산 마감, 새로 만든 아티스트·CP·묶음·소속사, 소셜 로그인으로 생긴 계정, 폰 푸시 등록. 그대로: 데모 계정 6개, 앱 설치, 서버 설정, 이 체크리스트 결과.

버튼이 안 보이거나 실패할 때: Railway → toffee → Variables → DEMO_SEED를 reset으로 바꾸고 Deploy → 배포가 끝나면 다시 true로 바꾸고 Deploy(이걸 안 하면 배포할 때마다 초기화됨).
