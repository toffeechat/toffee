토피 소속사 제안

목표는 "이 배우로, 이때부터 파일럿 하겠다"는 답 한 줄입니다. 연락은 글로 시작하고, 대화는 화상 미팅이나 방콕 방문으로 합니다. 미팅에는 통역사가 함께합니다.

연락 흐름

  1. 1메일·메시지태국어 + 영어 + 한국어 한 통. 공식 메일, LINE 공식 계정, 페이스북 페이지
  2. 2후속 메일답이 없으면 7일 뒤 짧게 한 번
  3. 3화상 미팅 또는 방문30분, 통역사 동반. 데모를 화면으로 같이 봄
  4. 4파일럿 의사배우 이름·시작 시기를 메일로 받아 둠

메일에는 화상 미팅과 방콕 방문 두 가지를 제안하고 상대가 고르게 합니다. 날짜가 정해지면 통역사를 구합니다. 통역 비용은 사업화 장부에 기록합니다.

누구에게

중소 제작사와 신인 위주 소속사부터 연락합니다. 대형사는 실적이 생긴 뒤에 연락합니다.

배우를 고르는 기준

  • SNS 팔로워 10만~100만 명
  • 해외 팬이 많음 (영어·필리핀 댓글이 많음)
  • CP로 활동 중이거나 최근 작품이 있음
  • 팬미팅을 해 본 적이 있음
  • 버블 같은 유료 메시지 채널이 아직 없음
  • 배우가 직접 하루 1번 이상 보낼 수 있음

짧게, 숫자 하나

  1. 토피가 무엇인지 두 줄
  2. 제안 조건: 비용 없음, 비독점, 60%(창립 파트너 70%)
  3. 수익 예시 하나: 팬 1,000명이면 월 약 ฿83,000
  4. 데모 링크
  5. 화상 미팅 또는 방문 제안

  2. 소속사가 얻는 것: 새 수익, 해외 팬 데이터, 운영 부담 없음

  1. 인사·소개 3분
